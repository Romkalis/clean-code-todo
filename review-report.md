## Неясные имена

### 1. Опечатка в имени списка незавершённых задач

**Место:** `app.js`, строка 12: `incompletedTasksList`.

**Проблема:** в имени переменной использовано `incompleted`, тогда как HTML ID — `incompleteTasks` и в английском обычно используется `incomplete`. Это затрудняет поиск соответствий между JS и HTML и повышает риск опечаток при дальнейших изменениях.

**Когда проявляется:** при чтении или изменении логики добавления и переноса задач между списками.

**Как проверить исправление:** выполнить поиск по старому имени, убедиться, что все ссылки обновлены, затем проверить добавление задачи и перенос её в оба списка.

## Дополнительные замечания по поведению

### 1. Несуществующий метод поиска кнопки останавливает весь скрипт

**Место:** `app.js`, строка 11: `document.getElementsById('newTaskButton')`.

**Проблема:** у `document` нет метода `getElementsById`. Вызов завершится ошибкой `TypeError` ещё при выполнении скрипта, поэтому строка добавления обработчика не сработает и дальнейшая инициализация событий не произойдёт.

**Когда проявляется:** сразу при загрузке страницы в браузере; приложение не сможет выполнять обработчики добавления, редактирования, удаления и переключения задач.

**Как проверить исправление:** открыть страницу и проверить консоль на отсутствие ошибки; затем добавить, отредактировать, удалить и переместить задачу между списками.

### 2. Подпись редактирования не обновляется вместе с названием задачи

**Место:** `app.js`, строки 23 и 39: `editInputLabel.innerText`; обработчик `editTask`, строки 65–79.

**Проблема:** доступная подпись поля создаётся из исходного названия задачи, но при сохранении нового названия обновляется только видимая подпись `.task`. Подпись поля редактирования остаётся со старым названием.

**Когда проявляется:** после переименования задачи, когда пользователь снова переходит к полю её редактирования.

**Как проверить исправление:** переименовать задачу и проверить, что текст подписи поля редактирования соответствует новому названию; убедиться, что поле продолжает редактировать нужную задачу.
